# Talks and presentations

No presentation entries have been added yet.

## Add an update

Either send the presentation details, photographs and optional slides in the
ChatGPT conversation, or use the repository's **Issues → New issue → Add a
presentation** form.

Include the title, event, date and a brief summary. The GitHub issue form and
its attachments are public. Submitting the form does not trigger automatic
publication or notify a connected assistant automatically. Share the issue
link in the conversation when it is ready.

## Entry structure

Use one folder per presentation:

```
presentations/
  YYYY-MM-DD-short-title/
    README.md
    slides.pdf
    event-photo.jpg
```

Copy TEMPLATE.md into the new folder as README.md, complete the fields and
remove unused sections. Slides and photographs are optional. Add a link to
each completed entry at the top of this index.
